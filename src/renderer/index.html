Before starting

Install 64-bit QEMU for Windows and add its folder to PATH. Restart DualCore VM after installing it. Create a virtual disk and select an installer ISO for each guest.

Windows 11 guests also need UEFI firmware and a TPM 2.0 device; this initial QEMU launcher does not configure those yet. Do not start Windows 11 installation until that support is added.

Virtual disk files are created separately from your real drives. DualCore VM does not repartition or format your host disks.
